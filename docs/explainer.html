03 /

Why it looks random

Every pair of columns has the same population distribution as independent uniform noise in the continuous construction—even though the four columns together encode a shape.

Why δ = 3

A row combination is (a, a+b, −b, −a+b). Any two zero coordinates force a=b=0: the six 2-column minors are all nonzero.

w₁ has exactly 3 nonzero entries, so the minimum is 3, not just ≥3.

The one-line reason for uniformity

Fix any one or two coordinates: the remaining columns still span the two hidden directions over ℚ, so their torus map is onto and sends uniform noise to uniform noise.

Thus the fixed coordinates are independent uniform even after conditioning on any u. This is a population guarantee, not a claim that six points fill every scatter plot.

Grid caveat. The exact eighths are for the arithmetic only. The minor for columns 2 and 4 is 2, not invertible mod 8; fixing u=(4/8,4/8) lets (x₁,x₃) occupy only 32 of 64 grid cells. The 1,200-point comparison uses true continuous-style sampling, not rounded eighths.

What should the agent return?

A machine-readable certificate: integer directions plus a compact drawing in those coordinates. The report can explain the discovery, but the score does not depend on an LLM judge.

Because A is integer and unimodular, this is a bijection on the hidden torus. The grader applies A⁻¹ to the entire drawing, including its lifted edges.

The torus identifies opposite edges of the square. A segment from (7/8,3/8) to (1/8,5/8) can wrap, rather than cut across the middle.
start = (7,3)/8
end = (1,5)/8

A lift is an integer offset added to the second vertex of an edge. It is not optional in a general torus drawing: endpoints alone do not specify the path. In the equivalent certificate, the first edge also uses a nonzero lift.


06 /
Score the discovery, not a detector
A · Recover the hidden directions
Compare rational row spaces (equivalently their saturated integer lattices). Let H be the submitted weights and J the stacked matrix [B;H].
r = rank(B) = 2;   h = rank(H);   j = rank(J)
intersection dimension = r + h − j
SΛ = (r + h − j) / j
Hand check: B has the invertible pivot minor on x₁,x₃; the equivalent rows are obtained by invertible A. The wrong rows e₁ and e₂ add two independent directions (use x₃ and x₄ to eliminate the B rows first). Maximum accepted rank = 3.
B · Recover the geometry
Only score geometry after complete lattice recovery. Map the submitted drawing back to the true basis first. Use toroidal distance, tolerance ε = 1/8, and independent private samples from the true and submitted shapes.

Squared distances are expressed in grid units: d² means 64 × actual squared distance. Hit iff d² ≤ 1. Example: two grid steps away gives d²=4 and is a miss. Tables use exact point-to-segment distances with periodic copies.
The six-by-six test points are selected for an easy hand check; a real grader draws many private test points from each geometry and measures arclength-weighted coverage. It caps the certificate's complexity and scores at fixed tolerances.
C · Topology: more than visible pixels
For these finite graphs, degree is the number of incident edges. Components C and cycle count L = E − V + C are computed from the graph. These examples have no loops.
X vs. two touching V's
The split graph uses two distinct center IDs at exactly the same coordinate. Its abstract incidence differs, but its point support is identical. Without extra information no agent can infer that invisible distinction: merge coincident junctions by convention, or use a real resolvable gap. Do not penalize the split as a hidden physical fact.
Y vs. a single bent line
The bent line has no degree-3 vertex and is missing the upward arm. Here the support actually changes, so the difference is detectable.
Keep metrics distinct. Geometry alone does not certify topology. Report graph diagnostics separately (or define a topology-aware score in advance). Only score topology that is identifiable from samples at the chosen resolution.

One final disguise
Map each scalar to (cos 2πx, sin 2πx), then randomly rotate all eight coordinates and add small matched noise. The null undergoes the same transformation. The agent first has to recover the circle planes, then decode the angles and find the lattice and drawing. No hand calculations needed here.
This extra stage has been tested in larger pilots; it is optional in this teaching example. Low-degree moment concealment survives the rotation, but stronger empirical detection and recovery gates are still necessary.
